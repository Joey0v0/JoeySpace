## 结论

F6 真实环境结果：**任务 6—9、10—11 的已测链路及维护窗口中的 Push 进程停止/恢复专项 PASS；模型稳定性仍未确认**。任务 7 首次发现切换页面后旧 WS 连接会删除新连接的 Redis 在线路由，`475b985` 加入连接租约；只读审查又发现并发重连时旧连接可晚于新连接写入租约，`db191c4` 将注册与发布串行化并拒绝旧连接发布。复审发现此时 Redis 写入持有全局 Hub 锁，`33defb7` 再将顺序保护缩小至同一用户，给 Redis 写入 5 秒上限；定向测试先红后绿，全仓 Go 测试通过。最终 `33defb7` 镜像切换后双浏览器再次通过双向群/私聊 WS 与历史 ID、团队范围、未读/@我、显式已读、历史分页和离线补拉；复测团队 `2108854595408109568`、群 `2108854595827544064`。任务 8 的真实创建、本人列表/来源、三态、冲突和通知链通过；账号与资源 ID 见本清单前文。第 6 步 Chrome 首次在本机受限沙箱中 DevTools 连接中断，获准的非沙箱复测通过。
