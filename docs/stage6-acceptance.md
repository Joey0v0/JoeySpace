# 阶段 6：单项链路与多项逐项确认验收清单

本清单覆盖当前单项链路：用户在团队群页面显式生成草稿，本人读取、编辑、选择负责人并确认；Agent 调用 Task 创建任务、保存任务 ID，并按配置尝试独立机器人回帖。负责人称呼提取、严格成员匹配及人工选择已接线；时间原文提取、有限解析、依据持久保存、本人处理歧义及确认保护也已接线。2026-10-04 多项原子保存、集合/指定项读取、旧接口隔离、本人逐项文字/负责人/时间编辑、逐项确认/固定Task键/结果保存/显式重试，以及未提交项本人跳过已通过本地组合验证；多项页面、逐项回帖及群内 `@AI` 仍未实现。这里记录代码与本地替身验证，全部真实环境条目仍待验收，阶段 6 不标全部完成。

## 调用链与成功含义

1. 页面经 Gateway 请求 Agent；Agent 以原用户 Token 确认身份和当前团队群访问权，通过 Eino 生成并持久保存草稿。
2. 读取、编辑、负责人选择、确认均只允许发起人本人，并重新核对当前团队群权限；模型只提取称呼，User 解析真实成员。歧义须人工处理，正负责人在待确认阶段和 Task 创建阶段复核当前资格。
3. 时间模型只提取原文和来源，Agent 按授权原文及固定参考解释；原依据与当前最终时间分别保存。needs_input 须本人补时间或明确不设。确认比较本人读取的版本、文字、已审查负责人、截止时间及新依据状态后，先冻结草稿和稳定请求键，再调用 Task；Task 根据创建者与请求键去重。Agent 保存任务 ID 和成功状态后才向页面报告成功；回帖状态另行记录，受理不等于送达。
4. 超时或结果保存失败后，任务可能已经创建。页面必须先重读，再由本人显式重试同一运行；当前没有后台自动恢复。

`waiting_confirmation` 表示可编辑、待本人确认；`creating` 表示内容已冻结、结果尚未确定，不表示后台正在工作；`succeeded` 只表示任务创建结果已保存，不表示已向群发送消息。HTTP 的 `task_id` 始终是字符串：前两种状态为 `"0"`，成功为正整数任务 ID。

具体事务和失败规则见[确认设计](agent-confirmation-design.md)、[负责人契约](assignee-collaboration-contract.md)、[人工截止时间审查](agent-deadline-design.md#7-人工截止时间闭环审查)、[自动时间闭环审查](deadline-auto-review.md)及[回帖设计](agent-group-reply-design.md)，选择与确认状态见[架构记录](architecture-decisions.md) A35—A53。

## 故障与恢复验收（全部待执行）

只在隔离环境注入故障，先固定运行 ID、Task 请求键和任务数量基线；每次恢复由本人执行，不增加后台自动重试。

| 故障位置 | 期望结果与核对方式 | 状态 |
| --- | --- | --- |
| 冻结事务未成功 | 事务回滚，不调用 Task；恢复后重读真实状态，避免凭 HTTP 错误猜测是否冻结 | 未验收 |
| 冻结后、调用 Task 前终止 Agent | 重启仍能读到冻结内容及原请求键；本人重试能创建任务，不能解冻后以新内容继续同一操作 | 未验收 |
| Task 已提交但响应丢失 | 页面提示结果不确定，重读 `creating` 后再确认；保留冻结负责人/版本，目标后续离队不改变已冻结结果，Task 同键返回原任务 ID，没有重复任务 | 未验收 |
| Task 成功、Agent 保存结果失败 | 不向页面报告已保存成功；本人同键重试恢复原任务 ID，再持久记录成功 | 未验收 |
| Agent 已保存成功但 HTTP 响应丢失 | 刷新重读得到原任务 ID；再次确认返回同一结果，不重新创建任务 | 未验收 |
| 数据库真实并发与重启 | 用实际 MySQL 验证锁、事务、唯一约束及重启后记录；替身测试结果不能替代该项 | 未验收 |
| 权限撤销后结果仍不确定 | 再次操作被拒绝；保留冻结记录，不伪装为失败或让他人接手。管理员核对与补偿流程尚未实现 | 未验收 |
| IM、Task 或 Agent 不可用/超时 | 返回对应失败状态，不泄露内部错误，不报告假成功；实际延迟是否符合请求预算需实测 | 未验收 |
| 冻结后 Task 永久拒绝 | 保留冻结记录并要求核对，不能改写为未创建；当前没有取消、解冻或自动补偿入口 | 未验收 |

验收记录至少包含代码版本、迁移版本、账号角色、运行/团队/群/任务 ID、草稿版本与审查负责人、时间来源/参考/处理状态、HTTP 状态、业务 `code`、脱敏响应摘要、相关行数和恢复动作；不保存密码、密钥、完整 Token 或私有消息正文。上述项目通过后，也只表明当前单项链验收；已接线的时间及群回帖仍须真实验收，多项草稿及群内触发继续按后续步骤实现。
