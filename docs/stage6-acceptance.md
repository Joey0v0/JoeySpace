# 阶段 6：单项草稿确认创建验收清单

本清单只覆盖已经实现的链路：用户在团队群页面显式生成一项草稿，本人读取、编辑、确认；Agent 调用 Task 创建任务并保存任务 ID。群回帖、负责人匹配、模糊时间解析、多项草稿及群内 `@AI` 均未实现，不能据此把阶段 6 标记为全部完成。

## 调用链与成功含义

1. 页面经 Gateway 请求 Agent；Agent 以原用户 Token 确认身份和当前团队群访问权，通过 Eino 生成并持久保存草稿。
2. 读取、编辑、确认均只允许发起人本人，并重新核对当前团队群权限；模型输出不能决定身份或权限。
3. 确认先冻结草稿和稳定请求键，再调用 Task；Task 根据创建者与请求键去重。Agent 保存任务 ID 和成功状态后才向页面报告成功。
4. 超时或结果保存失败后，任务可能已经创建。页面必须先重读，再由本人显式重试同一运行；当前没有后台自动恢复。

`waiting_confirmation` 表示可编辑、待本人确认；`creating` 表示内容已冻结、结果尚未确定，不表示后台正在工作；`succeeded` 只表示任务创建结果已保存，不表示已向群发送消息。HTTP 的 `task_id` 始终是字符串：前两种状态为 `"0"`，成功为正整数任务 ID。

具体事务和失败规则见[确认设计](agent-confirmation-design.md)，已确定的方案见[架构记录](architecture-decisions.md) A35—A41。

## 业务与页面验收（全部待执行）

| 场景 | 动作与期望结果 | 状态 |
| --- | --- | --- |
| 生成不执行 | A 生成草稿；保存运行 ID，刷新后能重读。尚未确认时 Task 表与群消息均不新增结果 | 未验收 |
| 生成请求重试 | 使用原请求键和相同范围、内容重试，得到同一运行；同键不同内容被拒绝。并发仍可能重复调用模型，不能据此承诺只计费一次 | 未验收 |
| 来源与授权 | 正常来源指向有权读取的当前群消息；非法来源、其他团队或其他群不能绕过后端校验。负责人和截止时间当前不会由模型自动填充 | 未验收 |
| 仅发起人可操作 | B 即使同群，也不能读取、修改或确认 A 的运行；C、另一团队账号不能访问该草稿 | 未验收 |
| 当前资格 | A 生成后失去群或团队资格，再读取、编辑、确认均被拒绝；已成功的运行也不能绕过当前范围检查 | 未验收 |
| 正常编辑确认 | A 修改标题/说明并保存，再确认；Task 中创建内容与冻结草稿一致，页面显示完整任务 ID，后续不可编辑 | 未验收 |
| 未保存文字 | 修改文字后直接确认被页面阻止；不能把页面尚未保存的文字误当作实际创建内容 | 未验收 |
| 两窗口冲突 | 两窗口读到相同旧值，第一窗口保存后，第二窗口保存或确认旧内容收到 409；不覆盖新内容，先重读再操作 | 未验收 |
| 重复确认 | 重复点击、刷新后重试及并发确认同一运行；Task 最终仅一条对应创建记录，Agent 保存同一个任务 ID。不要求 Task RPC 只调用一次 | 未验收 |
| 精确 ID 与安全显示 | 使用超过 JavaScript 安全整数范围的运行、群、消息及任务 ID；请求和显示保持精确字符串。标题中含 HTML 时显示为文字 | 未验收 |
| 切换上下文 | 请求中途更换登录身份、团队或群，再切回；旧成功或错误响应不能覆盖当前草稿或误启用确认 | 未验收 |

## 故障与恢复验收（全部待执行）

只在隔离环境注入故障，先固定运行 ID、Task 请求键和任务数量基线；每次恢复由本人执行，不增加后台自动重试。

| 故障位置 | 期望结果与核对方式 | 状态 |
| --- | --- | --- |
| 冻结事务未成功 | 事务回滚，不调用 Task；恢复后重读真实状态，避免凭 HTTP 错误猜测是否冻结 | 未验收 |
| 冻结后、调用 Task 前终止 Agent | 重启仍能读到冻结内容及原请求键；本人重试能创建任务，不能解冻后以新内容继续同一操作 | 未验收 |
| Task 已提交但响应丢失 | 页面提示结果不确定，重读 `creating` 后再确认；Task 同键返回原任务 ID，最终没有重复任务 | 未验收 |
| Task 成功、Agent 保存结果失败 | 不向页面报告已保存成功；本人同键重试恢复原任务 ID，再持久记录成功 | 未验收 |
| Agent 已保存成功但 HTTP 响应丢失 | 刷新重读得到原任务 ID；再次确认返回同一结果，不重新创建任务 | 未验收 |
| 数据库真实并发与重启 | 用实际 MySQL 验证锁、事务、唯一约束及重启后记录；替身测试结果不能替代该项 | 未验收 |
| 权限撤销后结果仍不确定 | 再次操作被拒绝；保留冻结记录，不伪装为失败或让他人接手。管理员核对与补偿流程尚未实现 | 未验收 |
| IM、Task 或 Agent 不可用/超时 | 返回对应失败状态，不泄露内部错误，不报告假成功；实际延迟是否符合请求预算需实测 | 未验收 |
| 冻结后 Task 永久拒绝 | 保留冻结记录并要求核对，不能改写为未创建；当前没有取消、解冻或自动补偿入口 | 未验收 |

验收记录至少包含代码版本、迁移版本、账号角色、运行/团队/群/任务 ID、HTTP 状态、业务 `code`、脱敏响应摘要、相关行数和恢复动作；不保存密码、密钥、完整 Token 或私有消息正文。上述项目通过后，也只表明当前单项确认链验收；群回帖和阶段 6 其余功能仍须分别实现和验证。
