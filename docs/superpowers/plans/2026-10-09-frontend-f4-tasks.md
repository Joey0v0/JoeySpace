# JoeySpace F4 任务与通知实施计划（待审查）

**目标：**在 F3 真实聊天基线上交付跨团队本人任务、任务详情/创建/三态、来源定位和持久通知工作区。设计与待确认选择见 [F4 设计](../../frontend-f4-tasks-design.md)。本文只是实施顺序，不表示业务能力已经完成。

**共同基线：**`codex/frontend-f4-tasks` 从 F3 `69bb016` 建立。主 agent 负责协议、生成代码、迁移、共同文档、集成和集中验证；最多三个执行 agent 在独立 worktree/分支工作，不自行合 main、推送或部署。F12—F16 获用户确认后才启动受影响实现。

## 九个独立小步骤

1. **固定 F12—F16 契约和 037。**明确 Task 本人任务/详情/通知字段、状态预期值、IM 来源上下文、字符串 ID、分页及错误映射；用真实 MySQL `EXPLAIN` 决定任务和通知索引。共同协议、生成代码、迁移和文档由主 agent 修改。
2. **Task 本人任务和详情。**实现跨团队本人待处理/已完成查询、可选团队筛选、稳定游标、当前资格复核及深链接详情；保留原团队列表。验证多团队、离队、分页、大 ID 和数据库失败。
3. **Gateway 任务读模型。**接本人列表和详情，批量补团队名及当前页成员显示名；服务错误不伪装为空列表。验证当前页有限组合、账号切换和缺失资料兜底。
4. **状态并发与创建契约。**Task/Gateway 接 `expected_status` 冲突；Vue 状态操作按重读结果处理超时。新建表单使用稳定幂等键、团队成员选择和不确定结果同键重试。
5. **IM 来源上下文。**实现有权目标消息及邻近上下文 RPC/HTTP，复用团队群资格、关闭代际、机器人和提及字段；验证目标不存在、离群、改群、旧消息和固定上限。
6. **Vue 任务列表与详情。**替换 `TaskPreview`，实现待处理/已完成、团队筛选、分组、分页、空/错/重试、深链接和右侧详情；所有账号与筛选请求带世代隔离。
7. **Vue 创建与来源往返。**任务工作区和群消息入口共用表单；成功打开详情，来源上下文高亮并支持浏览器返回。验证未持久消息、私聊、超时、重复提交和撤权。
8. **通知聚合与实时提示。**Task/Gateway 提供跨团队本人通知及未读数；Vue 在任务工作区显示通知、显式已读，消息页和任务页复用同一种路由内 WS 客户端，通过轻量共享信号显示导航圆点，并在提示/重连后串行刷新权威数据。
9. **集中审查与验证。**逐提交核对权限、数据归属和文件边界；运行相关包、全仓 Go、前端测试/类型检查/构建、实际 HTTP→TCP gRPC 组合及 1280/1440/1920 浏览器替身流程，记录真实 MySQL/Kafka/mTLS/云端仍未验证部分，提交用户审查。

## 计划边界

本批不实现任务编辑、看板、拖拽、优先级、子任务、评论、附件、批量操作、通知归档/稍后处理、浏览器系统通知或 F5 AI 草稿界面。F4 审查通过后也只按上述九步推进；遇到索引、跨服务资格或实时连接边界变化，先更新架构记录并暂停受影响实现。
